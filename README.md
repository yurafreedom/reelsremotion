# ReelsRemotion — монтаж вертикальных роликов

**Чтобы смонтировать ролик, установите Node.js 22, откройте терминал в папке проекта и выполните `npm install`, затем `npm run dev`. Откройте [localhost:5173](http://localhost:5173/).** В браузере можно загрузить видео, обрезать его, поправить текст, добавить картинки и сохранить MP4. Второй способ — дать **Claude Code или GPT в среде с доступом к папке проекта и терминалу** исходники, референсы и задание: помощник подготовит монтаж и запустит сборку видео. Для него браузерный редактор не обязателен. Это рабочий прототип для вертикальных роликов **1080×1920**, а не законченный универсальный видеоредактор.

## Сначала выберите способ

| | Через Claude / GPT | В браузере |
|---|---|---|
| Как вы работаете | Описываете результат, даёте материалы, обсуждаете и проверяете монтаж | Сами нажимаете кнопки, двигаете клипы и меняете свойства |
| С чего начать | Идея, исходное видео, примеры желаемого стиля | Готовый короткий клип или подготовленный проект |
| Кто выбирает фрагменты и пишет сценарий | Вы вместе с помощником | Вы; встроенного помощника нет |
| Субтитры | Помощник запускает отдельное распознавание речи и готовит текст с таймингами | Можно менять готовый текст и дублировать его; автоматического распознавания нет |
| Музыка | Помощник добавляет файл и настраивает громкость | Можно менять уже импортированный аудиоклип; кнопки загрузки музыки пока нет |
| Для чего удобнее | Собрать ролик по сценарию, особенно из длинного исходника | Посмотреть результат и сделать точечные правки |
| Инструкция от начала до результата | **[Монтаж через Claude или GPT](docs/AI_WORKFLOW.md)** | **[Монтаж в браузере](editor/README.md)** |

Оба способа используют один движок и файл `timeline.json` — «монтажный лист», где записано, что и когда показывать. Само видео хранится отдельно. Передать проект между способами можно, но нужно правильно перенести и его медиафайлы: [как это сделать](docs/AI_WORKFLOW.md#передать-монтаж-в-браузер-и-обратно).

## Запуск с нуля

1. Установите [Node.js](https://nodejs.org/en/download) **ветки 22**. Проверенная здесь версия — 22.20.0. npm устанавливается вместе с ним. Для скачивания через команду ниже нужен [Git](https://git-scm.com/downloads); можно вместо этого скачать ZIP репозитория и распаковать.
2. Откройте Terminal на macOS или терминал на своём компьютере. Скачайте проект:

   ```bash
   git clone https://github.com/yurafreedom/reelsremotion.git
   cd reelsremotion
   ```

   Если проект уже скачан, откройте терминал в существующей папке. Повторно скачивать его не нужно. Папка может называться `ReelsRemotion` или иначе; внутри должен быть `package.json`.

3. Выполните команды по очереди:

   ```bash
   npm install
   npm run dev
   ```

4. Дождитесь строки `Local: http://localhost:5173/` и откройте этот адрес. Если порт занят, в терминале может появиться другой адрес — используйте именно его.
5. Оставьте терминал открытым. Пока команда работает, работают редактор, загрузка файлов и экспорт. Остановка — `Ctrl+C`.

Старый способ тоже работает: после установки из корня выполните `cd editor`, затем `npm run dev`. **Второй `npm install` внутри `editor/` не нужен.** Для воспроизводимой установки на новой копии можно использовать `npm ci` вместо `npm install`: он берёт точные версии из `package-lock.json`.

При первом открытии показывается короткий **учебный пример**, а не ваши старые ролики. Надпись `VIDEO` — заглушка, которую нужно заменить своим клипом. Нажмите Play, чтобы увидеть анимацию текста.

### Что ещё понадобится

- **Для ручной работы в браузере:** исходное видео и современный настольный браузер. Отдельный API-ключ не нужен.
- **Для первого экспорта:** интернет для загрузки служебного Chrome, если он ещё не установлен Remotion, и шрифтов. Сборка MP4 происходит на вашем компьютере.
- **Для монтажа из длинных исходников через помощника:** `ffmpeg` и `ffprobe` для нарезки и проверки файлов. Для распознавания речи — Python и отдельно установленный `faster-whisper`; `npm install` их не устанавливает. Подробности — в инструкции для помощника.
- **Для Claude/GPT:** доступ к соответствующему инструменту и разрешённая работа с локальным проектом. ReelsRemotion сам не подключается к модели и не оплачивает её работу.

## Что уже можно получить

Вертикальный MP4 с последовательностью видеофрагментов, звуком исходника, текстом и анимацией, изображениями, простыми фигурами, переходами и музыкой. Через сценарии доступны подготовка фрагментов, субтитры по распознанной речи, вставки дополнительного видео и сборка по монтажному плану.

Программа **монтирует ваши материалы**. Встроенной генерации нового видеоряда, озвучки, поиска стоков или кнопки «сделай ролик по ссылке» нет. Референс помогает человеку или помощнику понять стиль; браузер сам его не анализирует.

## На какой стадии продукт

**По проверке 9 ноября 2026 года: инструмент для монтажа с помощником уже работоспособен; браузерный редактор — ранний прототип для ручных правок.** Номера `1.0.0` в корневом пакете, `2.0.0` в заголовке редактора и `v3` в данных относятся к разным вещам и не означают готовый коммерческий релиз.

Главные ограничения, которые важно знать до работы:

- **Нет автосохранения.** Перед обновлением или закрытием вкладки нажимайте `Export timeline.json`. Загруженные видео остаются на диске, но несохранённый монтаж пропадёт.
- **Нет кнопки нового текста.** Можно дублировать существующую надпись или импортировать проект с текстом.
- **Нет загрузки музыкального клипа через интерфейс.** `+ Audio track` создаёт только пустую дорожку. Музыку нужно добавить в JSON через помощника; дальше её можно регулировать в редакторе.
- **Нет автоматических субтитров в браузере.** Распознавание и подготовка таймингов — отдельный этап.
- **Удаление видео не сдвигает субтитры и музыку вместе с ним.** После изменения структуры нужно проверить синхронизацию.
- **Для текущего редактора используйте экспорт 30 fps.** Кнопка 60 fps есть, но пересчёт времени написан для старых данных: для нынешних дорожек он может вдвое ускорить ролик. Это известная неисправность, не обещание «более плавного видео».
- Проект сохраняется как JSON и отдельные медиафайлы. Нет единого переносимого архива, библиотеки проектов и восстановления несохранённой сессии.

Подробно: **[стадия продукта, ограничения и что нужно доделать](docs/PRODUCT_STATUS.md)**. Список возможностей именно интерфейса — в [инструкции редактора](editor/README.md).

## Куда складывать файлы

Для каждого ролика придумайте короткое имя латиницей, например `my-first-reel`.

| Что у вас есть | Куда положить для работы с помощником |
|---|---|
| Длинное исходное видео | `reel-input/my-first-reel/source/` |
| Ролики-примеры, скриншоты стиля | `reference/my-first-reel/` |
| Идея, пожелания, сценарий | `reel-input/my-first-reel/BRIEF.md` |
| Текст речи / распознавание | `reel-input/my-first-reel/transcript/` |
| Короткие вырезанные фрагменты для сборки | `reel-input/my-first-reel/public/clips/` |
| Используемые картинки, вставки, музыка | `reel-input/my-first-reel/public/media/` |
| Готовый монтажный лист | `reel-input/my-first-reel/timeline.json` |
| Готовое видео | `out/my-first-reel.mp4` |

Эти папки — соглашение об организации, а не автоматический загрузчик. Само появление файлов в папке не запускает монтаж. Не кладите длинные исходники и референсы в `public/`: эту папку движок копирует при подготовке видео.

**В браузерном способе** кнопки `+ Video` и `+ Image` сами копируют выбранные файлы в общую папку `public/media/`. Это другая папка, чем `reel-input/my-first-reel/public/media/`; они не синхронизируются автоматически.

## Если не запускается

### Открывается пустой экран

В проверенной локальной установке плеер был **4.0.541**, а основной Remotion — **4.0.483**. Поэтому сервер запускался, а страница падала с `NoReactInternals.validateDefaultPremountInSeconds is not a function`. Сборка сайта при этом могла завершаться успешно.

В исправленной конфигурации все пакеты Remotion закреплены на **4.0.541**, а плеер и инструменты рендера указаны напрямую. Остановите старый сервер, установите зависимости из корня и запустите заново:

```bash
npm install
npm run check:versions
npm run dev
```

Проверка должна закончиться `All packages have the correct version.` Обновите вкладку. Если остался старый кэш, остановите сервер и выполните `npm run dev -- --force`. Не обновляйте только один пакет Remotion: [почему версии должны совпадать](https://www.remotion.dev/docs/version-mismatch).

### Другие частые случаи

| Что происходит | Что сделать |
|---|---|
| `npm: command not found` | Установить Node.js и заново открыть терминал |
| `package.json` не найден | Перейти в папку скачанного проекта |
| Адрес не открывается | Проверить, что `npm run dev` ещё работает, и открыть адрес из строки `Local` |
| `Port 5173 is in use` | Проверить уже открытый сервер или использовать новый адрес, который выдал Vite |
| Ошибка загрузки файла или экспорта | Запускать через `npm run dev`; обычный просмотр собранной HTML-страницы не запускает нужный сервер |
| Импортированный проект есть, а видео отсутствует | Проверить пути к медиа: `media/clip.mp4` означает файл внутри выбранной папки `public` |
| Экспорт долго показывает `Starting…` | Первый запуск может скачивать Chrome; посмотреть сообщения терминала |
| `ffmpeg` / `faster_whisper` не найден | Установить отдельные инструменты из инструкции для Claude/GPT |

## Для разработки и проверки

```bash
npm run check:versions   # одинаковые версии Remotion
npm run typecheck       # проверка кода движка и редактора
npm test                # существующие проверки монтажа, импорта и анимации
npm run build:editor    # сборка интерфейса
npm run studio          # отдельный Remotion Studio для разработчика
```

`npm run studio` и `npm run dev` — разные приложения. `npm run render` рендерит встроенный пример, а не последний проект, открытый в браузере. Свой файл монтируйте по одной из двух инструкций выше.

Технические подробности: [схема данных](claude-code-CONTRACT.md), [производственный процесс](REELS_PRODUCTION_PIPELINE.md), [рендер без редактора](REELS_GENERATION_RUNBOOK.md), [старый программный конструктор](compose/README.md). Старые отчёты о конкретных сериях — исторические записи, а не инструкция для нового пользователя.
