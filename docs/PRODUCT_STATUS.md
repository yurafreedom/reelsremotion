# Состояние ReelsRemotion

Проверено по локальному коду и запуску **9 ноября 2026 года**. Это оценка работающей копии проекта, а не обещание готовности всех функций и не описание опубликованного онлайн-сервиса.

**Текущая стадия: рабочий инструмент для монтажа с помощником и ранний браузерный редактор.** Основной движок умеет собирать MP4, но путь от «у меня есть видео» до сохранённого проекта ещё требует подготовки файлов, понимания ограничений и проверки человеком.

## Два способа находятся на разной стадии

| Часть | Что уже есть | Что ещё требуется |
|---|---|---|
| Движок видео | Вертикальное видео, дорожки, текст, ключевые кадры, изображения, фигуры, переходы, звук, MP4 | Проверка реальных материалов и поведения на разных системах |
| Работа с Claude/GPT | Команды подготовки, нарезки, компиляции монтажного плана, проверки и рендера; примеры реальных проектов | Помощник с доступом к файлам и командам; сценарий и проверка результата; адаптация исторических шаблонов |
| Браузер | Предпросмотр, видео/картинки, ручные правки, разрезы, переходы, анимация, импорт/экспорт JSON, MP4 30 fps | Надёжное сохранение проектов, создание текста и музыки, связанные дорожки, исправление 60 fps и удобный старт с нуля |
| Готовый продукт для любого человека | Инструкции и учебная заготовка | Установка без терминала, понятный мастер первого ролика, восстановление работы, библиотека медиа и проектов |

У программы нет встроенного ИИ-сервиса. «Смонтировать через Claude/GPT» означает, что внешний помощник управляет локальными инструментами проекта. Вкус, точность цитат, переводов и речевых стыков не гарантируются успешным рендером.

## Почему локальная страница была пустой

В исходной локальной установке:

- `@remotion/cli` и пришедший через него `@remotion/player`: **4.0.541**;
- основной `remotion`, шрифты и переходы: **4.0.483**;
- `@remotion/player` не был объявлен как прямая зависимость проекта.

Сервер Vite стартовал и сборка интерфейса проходила, но браузер получал:

```text
TypeError: NoReactInternals.validateDefaultPremountInSeconds is not a function
at PlayerFn
```

Новый плеер обращался к функции, которой не было в старом движке. Это подтверждённая причина пустой страницы в этой установке. Отсутствие плеера среди прямых зависимостей не означало, что он вообще не установлен: он приходил косвенно и мог обновиться отдельно.

**Исправлено:** все используемые пакеты Remotion закреплены на 4.0.541 без `^`; плеер, сборщик и рендерер перечислены напрямую; обновлён lock-файл. Добавлены команды запуска и проверки из корня. Принцип одинаковых версий описан в [документации Remotion](https://www.remotion.dev/docs/version-mismatch).

Дополнительно исправлен список названий шрифтов: движок уже знал `nikulinaCondensed` и `nikulinaSans`, а редактор не включал их в список выбора и не проходил проверку типов.

## Подтверждённые ограничения

| Ограничение | Где видно в коде | Последствие |
|---|---|---|
| Нет автосохранения / восстановления | `editor/src/useTimelineHistory.tsx`, `Editor.tsx` | Монтаж живёт в памяти вкладки; сохранение — вручную через JSON |
| Нет кнопки создания нового текста | `Editor.tsx`, `panel/Panel.tsx` | Есть редактирование и `Duplicate`, но пустую текстовую дорожку нельзя заполнить кнопкой |
| Нет загрузки нового аудиоклипа | `media.ts`, `mediaActions.ts`, `Timeline.tsx` | `+ Audio track` добавляет пустую дорожку; работать можно с аудио из импортированного JSON |
| Удаление сдвигает только свою дорожку | `edits.ts`, `cut.test.ts` | После вырезания видео субтитры и музыка могут оказаться не на месте |
| 60 fps не поддерживает текущую схему | `editor/server/retime.mjs` | Пересчитывает `scenes`, но не `tracks` и общую длительность; использовать 30 fps |
| Разные папки медиа у двух путей | `editor/vite.config.ts`, `compose/render_reel.ts` | Импорт JSON не переносит файлы; нужен явный перенос и согласованные пути |
| Нет единого проекта-архива | `IoBar.tsx` | JSON и медиа нужно хранить и переносить вместе |
| Лимит загрузки одного файла 512 МиБ | `editor/server/media.mjs` | Длинные исходники нужно сначала нарезать |
| Не более 8 дорожек при добавлении через интерфейс | `editor/src/edits.ts` | Дополнительные слои ограничены |
| Экспорт и загрузка только с локальным dev-сервером | `editor/server/*.mjs` | Статическая сборка интерфейса не является работающим сервисом монтажа |
| Исторические пути в подготовке | `scripts/reel-pipeline.mjs` | Новому ролику нужно явно указать свои исходники и расшифровку |
| Разные настройки экспорта GUI и производственного помощника | `editor/server/render-worker.mjs`, `compose/render_reel.ts` | Один движок не гарантирует побайтовое совпадение: GUI использует JPEG-кадры, производственный путь — PNG и явно заданный bt709 |
| Шрифты не полностью переносимы | `src/fonts.ts` | Интернет-шрифты могут не загрузиться; Nikulina использует системные гарнитуры |

Широкий набор возможностей движка нельзя целиком объявлять возможностями интерфейса. Например, видео поверх видео, специальные правила появления слов и сложный стиль могут задаваться JSON/скриптом, не имея полноценной панели редактирования.

## Что доделать для самостоятельного монтажа обычным пользователем

Это **предлагаемый порядок дальнейшей разработки**, а не уже выполненные функции.

1. **Сохранность работы.** Автосохранение, открытие/создание проекта, предупреждение о несохранённых изменениях, восстановление после закрытия; архив с медиа и поиск потерянных файлов.
2. **Базовые операции.** `+ Text`, `+ Audio`, выбор музыкального файла, понятное создание пустого проекта, единообразные инструменты дублирования и удаления.
3. **Синхронизация.** Связанные видео/звук/субтитры, групповое перемещение и удаление, предсказуемое поведение переходов, звуковая волна.
4. **Надёжный экспорт.** Исправить пересчёт v3 для 60 fps, согласовать настройки с производственным рендером, добавить отмену и проверку ошибок/медиа перед запуском.
5. **Подготовка контента.** Импорт/распознавание субтитров с проверкой, удобная работа с фразами, библиотека стилей, настройка безопасных областей и шрифтов.
6. **Установка и обучение.** Установка без ручной подготовки окружения, русский интерфейс, пошаговый первый проект, тесты полного пути «загрузка → монтаж → сохранение → повторное открытие → MP4».

Практический способ работать сейчас: помощник готовит структуру и субтитры; человек оценивает результат и при необходимости делает локальные правки в браузере. Перед новой структурной нарезкой нужно учитывать отсутствие связанных дорожек.
