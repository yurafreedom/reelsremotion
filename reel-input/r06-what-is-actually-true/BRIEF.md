# R06 — What Do You Actually Know Is True?

STATUS=PREPRODUCTION / EDITORIAL REVIEW REQUIRED
FINAL_RENDER_AUTHORIZED=NO

## Core

Separate evidence from anxiety and expectation: what is actually true, what did the person actually do, and how much evidence is enough to believe them?

## Editorial objective

Build a compact question-led Reel that preserves the original English and uses phrase-level Russian translations without fake word alignment.

## Target structure

About 40 seconds; bilingual source with separate native and translation layers.

## Guardrails

- Source speech is never silently rewritten.
- Native ASR is machine-generated and must be checked by ear before approval.
- DISPLAY RU is a separate layer whenever source speech is English.
- B-roll is optional; talking-head reaction has priority.
- Final cuts/timeline/render wait for editorial approval.
